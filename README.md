# 🤖 Multilingual GenAI Chatbot - Interaction Analytics Pipeline

> An interaction analytics pipeline tracking multi-turn support interactions generated via Streamlit and Sarvam LLM API, analyzed using Pandas and Tableau.

## 📌 Project Highlights
* **Dataset Generation:** Generated a structured dataset of 1,000+ multi-turn customer interactions using Python, Streamlit, and Sarvam API.
* **Exploratory Data Analysis:** Conducted EDA via Pandas to evaluate chat durations and cross-analyze customer sentiment impacts on escalation.
* **BI Dashboard:** Built a Tableau dashboard tracking KPIs, revealing a 32.2% resolution rate vs. a 33.8% human escalation rate.

---

## 🚀 Key Metrics
* **Interactions Ingested:** 1,000+ records
* **Resolution Rate:** 32.2%
* **Escalation Rate:** 33.8%
